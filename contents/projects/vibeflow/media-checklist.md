# VibeFlow: media checklist

Save everything in `media/`. Capture at 1440x900 (or 1920x1080), desktop browser, no personal data on screen.
Run `npm run dev:web` and open http://127.0.0.1:5173. Choose a mode from the header. With Spotify not connected, the lyric visuals run in demo mode (a "Preview" label shows in Editorial).
