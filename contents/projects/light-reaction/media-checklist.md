# Media checklist

Save into `media\`. Run `python app.py` and open http://localhost:5000.

## Screenshots
- [ ] `hero.png` — dashboard in Movie Screen Sync mode with the colour halo/ambient glow showing a vivid colour.
- [ ] `physical-setup.jpg` — photo of the real light glowing next to the monitor (the best proof it works).
- [ ] `scan-modal.png` — "Discovered BLE Controllers" modal with a device list. (Consider blurring MAC addresses.)
- [ ] `sync-settings.png` — Screen Sync Settings panel (monitor select, FPS, threshold).
- [ ] `manual-mode.png` — Manual Color panel with Mood Presets.
- [ ] `gatt-report.png` — GATT Profile Report modal (optional, shows the protocol-inspection work).

## Recordings
- [ ] `demo-loop.webm` — 10-15 s: screen playing a scene while the dashboard glow and the physical light change together (see glimpse-plan.md shot list).
- [ ] `controls.webm` — optional, 5-8 s: moving FPS/threshold sliders and clicking presets.

## Notes
- Hide or blur real BLE MAC addresses before publishing.
- Avoid copyrighted film footage on screen; use your own or free footage.
